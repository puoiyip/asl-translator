## How it Was Made
This project was made as a part of Girls Who Code's "Basic Neural Nets" course. I used Python alongside various libraries including Pandas, Matplotlib, and Scikit Learn. I primarily adjusted the model by altering the size of the validation dataset and the number of hidden layers in the neural net model. I used a confusion matrix to examine the false negatives and false positives and make observations about whichs letters were misclassified the most. 
## Takeaways
While making this project, I mainly struggled with improving the accuracy of my model. After learning about and understanding how validation data works to improve the model, I was able to largely improve the accuracy of my both testing and training datasets. However, there was still a substantial difference between their accuracies, which may indicate overfitting.
